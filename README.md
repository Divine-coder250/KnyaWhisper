# KnyWhisper

This project is a mini Kinyarwanda Whisper for Intelligent Robotics work.  
It listens to Kinyarwanda audio, understands the question, and speaks back the answer.

## How to Run

- Install the below libraries(in the requirements)

- Record your audio questions and put them in the `audio/` folder.

- Then,Run the project,

- The recognized text and spoken answers will be saved in the `outputs/` folder.

## Requirements

- Python 3
- whisper
- gTTS
- torch
